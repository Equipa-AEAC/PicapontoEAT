# Pica Ponto

Pica Ponto is an RFID attendance management system for educational institutions.

Main users:

- Administrators
- Students

Hardware:

- ESP32
- RDM6300
- RFID Cards
- Buzzer
- RGB LED

Desktop:

- Tauri
- Vue
- TypeScript

Backend:

- OCaml

Database:

- SQLite

The project follows a modular architecture.
